# How to Update Senior Status

Quick steps to update a senior citizen's status in the system.

## Status Values

| Status | When to Use |
|--------|-------------|
| **Active** | Senior is residing in area and receiving services |
| **Inactive** | Senior temporarily unavailable or not receiving services |
| **Transferred** | Senior has moved to another location |
| **Deceased** | Senior has passed away |

## Steps

1. **Go to Directory** from the sidebar
2. **Search** for the senior citizen
3. **Click on the senior's record** to open details
4. **Find the "Status" field** in the profile
5. **Click the status** to open a dropdown
6. **Select the new status**
7. **Click "Save"** or "Update" to confirm

## Important Notes

- Updating to "Deceased" should be done with proper documentation
- Status changes are recorded in the system history
- Barangay Officials can only update seniors in their assigned barangay

## Verification

After updating, verify the change:
1. Search for the senior again
2. Confirm the status displays the new value
