# How-to Guides

How-to guides are task-oriented instructions that help you accomplish specific goals. Unlike tutorials, which teach you from scratch, how-to guides assume you have basic knowledge of the system.

## Available Guides

- [How to Log In](./login.md)
- [How to Search for a Senior Citizen](./search-senior.md)
- [How to Update Senior Status](./update-status.md)
- [How to Export Reports](./export-reports.md)
- [How to Manage Appointments](./manage-appointments.md)

## When to Use These Guides

Use a how-to guide when you:
- Know what you want to accomplish
- Need quick reference for a specific task
- Want to refresh your memory on a procedure
