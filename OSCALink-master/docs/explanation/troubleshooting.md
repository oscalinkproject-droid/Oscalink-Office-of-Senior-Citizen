# Troubleshooting

Common issues and their solutions.

## Login Issues

### "Invalid credentials" Error
- Verify email and password are correct
- Contact admin to reset password
- Check Caps Lock is off

### "Session expired" Error
- Clear browser cookies
- Try logging in again
- Use a modern browser (Chrome, Firefox, Edge)

### Can't Access Dashboard
- Verify your account is active
- Check your role has dashboard access
- Contact admin for permissions

## Data Issues

### Can't See Senior Records
- Verify your assigned barangay
- Check user role permissions
- Refresh the page

### Search Not Working
- Try partial name instead of full name
- Check for typos
- Use Registration ID format: OSCA-YYYY-XXXX

### Status Won't Update
- Ensure you have edit permissions
- Verify required fields are filled
- Try refreshing the page

## File Upload Issues

### Documents Won't Upload
- Check file format (JPG, PNG, PDF supported)
- Ensure file size is under 10MB
- Try a different browser

### Uploaded Files Not Visible
- Wait for upload to complete
- Check internet connection
- Verify Cloudinary is connected

## Report Issues

### "Export" Button Not Visible
- Reports page is Admin-only
- Verify your role is City Administrator

### PDF/CSV Not Generating
- Check date filters are valid
- Try a smaller date range
- Contact admin if issue persists

## Getting Help

If issues persist:
1. Note the exact error message
2. Take a screenshot
3. Contact your system administrator
