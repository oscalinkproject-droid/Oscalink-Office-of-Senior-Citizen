# Tutorials

Tutorials are step-by-step lessons that guide you through completing a specific task from start to finish. They are designed for new users who need to learn how to use OSCALink.

## What You'll Learn

These tutorials will teach you how to:

1. **Getting Started** — Log in and navigate the system
2. **Register a Senior Citizen** — Add new senior citizens to the system
3. **Process Assistance Requests** — Handle medical, financial, and other aid requests
4. **Schedule Appointments** — Set up appointments for senior citizens

## Before You Begin

Make sure you have:
- Valid login credentials from your system administrator
- Access to a computer with internet connection
- Your assigned role (City Administrator or Barangay Official)
