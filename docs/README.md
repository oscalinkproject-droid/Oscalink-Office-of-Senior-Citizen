Welcome to the OSCALink documentation. This documentation follows the **Diátaxis Framework** to help different users find the information they need.

## About OSCALink

**OSCALink** (Office for Senior Citizen Affairs Link) is a web-based municipal portal for Cotabato City that enables the OSCA office to:
- Monitor and manage senior citizen records
- Process assistance requests (Medical, Financial, Burial, Assistive Devices)
- Schedule appointments for municipal services
- Generate reports for city officials
