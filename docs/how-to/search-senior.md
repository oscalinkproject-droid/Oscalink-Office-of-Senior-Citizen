# How to Search for a Senior Citizen

Quick steps to find a senior citizen in the system.

## Steps

1. **Navigate to Directory** from the sidebar
2. **Use the search bar** at the top of the page
3. **Enter** the senior's name, ID, or partial information
4. Results appear automatically as you type

## Search Tips

- **Full name** — "Juan dela Cruz"
- **Partial name** — "Juan" or "Cruz"
- **Registration ID** — "OSCA-2026-0001"

## Filtering

You can also filter by:
- **Barangay/Sector** — Select from dropdown
- **Status** — Active, Inactive, Transferred, Deceased
- **Age range** — Set minimum and maximum age

## What You'll See

Search results display:
- Senior's name
- Age
- Barangay
- Status
- Contact number

Click on any result to view full details.
