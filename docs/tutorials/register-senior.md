# Registering a Senior Citizen

This tutorial will guide you through registering a new senior citizen in the OSCALink system.

## Prerequisites

- You must be logged into OSCALink
- You must have permission to add senior records (City Administrator or designated staff)

## Step 1: Navigate to the Directory

1. From the sidebar, click **"Directory"**
2. You will see a table listing all registered senior citizens
3. Look for the **"Register New Senior"** button (usually at the top of the page)

## Step 2: Open the Registration Form

1. Click **"Register New Senior"**
2. A registration modal (popup form) will appear
3. Fill in the required fields:

### Required Fields

| Field | Description | Example |
|-------|-------------|---------|
| **Registration ID** | Unique identifier for the senior | OSCA-2026-0001 |
| **Full Name** | Complete name of the senior | Juan dela Cruz |
| **Age** | Age in years | 72 |
| **Barangay** | Assigned barangay | Poblacion |
| **Contact Number** | Phone number | 09123456789 |

### Optional Fields

| Field | Description | Example |
|-------|-------------|---------|
| **Address** | Full residential address | Zone 2, Cotabato City |
| **Birthdate** | Date of birth | 1954-03-15 |
| **Emergency Contact** | Name and number of emergency contact | Maria Cruz - 09987654321 |

## Step 3: Upload Documents (Optional)

If you have digital copies of the senior's documents:

1. Look for the **"Upload Documents"** section in the form
2. Click the upload area or button
3. Select files from your computer (ID cards, medical records, etc.)
4. Files will be uploaded to Cloudinary for secure storage

> **Note:** Document uploads help prevent data loss and verify senior identity.

## Step 4: Submit the Registration

1. Review all entered information
2. Click **"Register"** or **"Submit"** button
3. Wait for confirmation message
4. The new senior will appear in the directory table

## Step 5: Verify Registration

1. The directory will automatically refresh
2. Search for the newly registered senior using the search bar
3. Verify all information is correct

---

## Senior Status Values

When a senior is first registered, their status is set to **"Pending"**. The system uses these status values:

| Status | Meaning |
|--------|---------|
| **Active** | Senior is currently residing in the area and receiving services |
| **Inactive** | Senior is temporarily unavailable or not receiving services |
| **Transferred** | Senior has moved to another location |
| **Deceased** | Senior has passed away |

## Troubleshooting

**Problem:** Registration fails with an error message
- **Solution:** Check that all required fields are filled. Ensure the Registration ID is unique.

**Problem:** Documents won't upload
- **Solution:** Check file format (JPG, PNG, PDF supported). Ensure file size is under 10MB.
