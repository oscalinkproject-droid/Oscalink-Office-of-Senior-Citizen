# Processing an Assistance Request

This tutorial will guide you through processing assistance requests from senior citizens.

## Objectives

By the end of this tutorial, you will be able to:
- View incoming assistance requests
- Process and update request status
- Communicate with applicants via email

## Types of Assistance

OSCALink handles four types of assistance requests:

| Type | Description |
|------|-------------|
| **Medical Support** | Hospital bills, medicines, medical equipment |
| **Financial Aid** | Cash assistance, emergency funds |
| **Burial Assistance** | Funeral and burial expenses |
| **Assistive Devices** | Wheelchairs, hearing aids, walking sticks |

## Step 1: Navigate to Requests

1. From the sidebar, click **"Requests"**
2. You will see the Assistance Requests board with category tabs

## Step 2: Filter by Category

The requests page has tabs for different assistance types:

- **All** — Shows all requests
- **Medical** — Medical support requests
- **Financial** — Financial aid requests
- **Burial** — Burial assistance requests
- **Devices** — Assistive device requests

Click on a tab to filter the view.

## Step 3: Review Requests

Each request is displayed as a card with:
- **Senior Name** — Who submitted the request
- **Type** — Category of assistance
- **Date** — When the request was submitted
- **Status** — Current processing status

### Request Status Values

| Status | Meaning |
|--------|---------|
| **Pending** | New request awaiting review |
| **In Progress** | Request is being processed |
| **Approved** | Request approved for release |
| **Released** | Assistance has been provided |
| **Rejected** | Request denied |

## Step 4: Process a Request

1. Click on a request card to view details
2. Review all information and attached documents
3. Use the action buttons to update status:

   - **Approve** — Mark as approved for release
   - **Reject** — Mark as denied (requires reason)
   - **Release** — Mark assistance as provided

## Step 5: Notify the Applicant (Automatic)

When you update a request status, the system automatically sends an email notification to the applicant using **Resend**:

- **Approved** — Email confirms approval and next steps
- **Released** — Email confirms assistance has been provided
- **Rejected** — Email explains why the request was denied

> **Note:** Ensure the applicant's email address is correctly recorded in their senior profile.

---

## Step 6: Generate Report

After processing requests, you can generate a summary:

1. Go to the **Reports** page (Admin only)
2. Select date range and category
3. Click **"Export PDF"** or **"Export CSV"**

## Troubleshooting

**Problem:** Can't see requests for my barangay
- **Solution:** Verify your user role and assigned barangay. Barangay Officials only see their barangay's data.

**Problem:** Email notification not sent
- **Solution:** Check the senior's profile has a valid email address.
